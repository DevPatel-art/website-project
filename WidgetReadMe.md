#  TechNest Dashboard with Widgets

This project is a responsive React-based dashboard featuring:

-  Addable/Removable Widgets:
  - ☀️ Weather Widget 
  - 💭 Quote of the Day 
  - ⚙️ Tech of the Day
    
# WidgetAPIs used
1. OpenWeatherMap: https://openweathermap.org/api
2. FavQs Quotes: https://favqs.com/api/qotd (used via https://allorigins.win to bypass CORS)

# Uses of Widgets
1. The OpenWeather API uses the api key and fetches the link to open weather to show us the weather we are living in.
2. The FavQs Quotes fetches the thought of the day and shows it in the dashboard
3. The tech feature is what i developed related to my website it calls a random tech product from the list and shows it as tech of the day the list is provided in the code

# CORS
CORS stands for Cross Origin Resource Sharing. It's a security feature in web browsers that controls which websites are allowed to make requests to different domains.

#  Technologies Used

- React
- OpenWeatherMap API
- Quotes API
- Javascript/CSS (custom styling)
